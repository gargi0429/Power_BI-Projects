# Data Analyst Career Intelligence Dashboard

## Project Overview

This Power BI dashboard analyzes global data profession trends using salary, hiring, company size, remote work, and geographic distribution data.

## Objectives

* Analyze salary trends across experience levels
* Identify top hiring job roles
* Understand company size distribution
* Evaluate remote work adoption
* Explore hiring patterns across countries

## Tools Used

* Power BI
* DAX
* Excel

## Key KPIs

* Total Jobs
* Average Salary
* Highest Salary
* Remote Jobs Percentage

## Dashboard Features

* Salary Analysis by Experience Level
* Top Job Titles
* Company Size Distribution
* Hiring Location Analysis
* Work Mode Distribution
* Interactive Year Filter

## Dataset

Data Science Job Salaries Dataset (Kaggle)

## Business Insights

* Executive-level professionals earn the highest salaries.
* Remote jobs account for a significant share of opportunities.
* Medium-sized companies contribute the largest proportion of job openings.
* Hiring demand is concentrated in a few key countries.
